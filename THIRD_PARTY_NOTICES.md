## MovieLens 32M

The bundled shared recommendation artifact is a transformation of the MovieLens 32M
research dataset from the GroupLens Research Project at the University of Minnesota.
It is included for personal, non-commercial research use under the conditions in the
[official MovieLens 32M README](https://files.grouplens.org/datasets/movielens/ml-32m-README.html).

Neither the University of Minnesota nor GroupLens endorses Movie Compass. The dataset
and derived artifact are provided without warranty. Commercial or revenue-bearing use
requires prior permission from GroupLens.

## TMDB

Movie Compass uses the TMDB API for movie metadata and images. This product uses the
TMDB API but is not endorsed or certified by TMDB.

TMDB API responses are kept in the local, ignored data directory and refreshed rather
than committed permanently. See the [TMDB API terms](https://www.themoviedb.org/api-terms-of-use)
and [TMDB attribution FAQ](https://developer.themoviedb.org/docs/faq).
